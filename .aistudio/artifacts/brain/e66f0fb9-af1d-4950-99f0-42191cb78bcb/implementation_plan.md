# استعادة صوت الخطأ (Buzzer) الكلاسيكي الأصلي

تهدف هذه الخطة إلى إرجاع مؤثر صوت الخطأ (❌ Strike Buzzer) إلى الصوت الكلاسيكي القوي الذي كان مستخدماً في النسخة السابقة تماماً، دون المساس بأي ميزة أو تصميم آخر في اللعبة.

## القرارات المعتمدة
> [!IMPORTANT]
> سيتم استبدال دالة `playStrike` الحالية بالنسخة الأصلية الكلاسيكية (ترددات الـ Sawtooth الخماسية مع اهتزاز LFO بتردد 40Hz ولمدة 0.85 ثانية)، مع الإبقاء على ربطها بوحدة التحكم في مستوى الصوت (`getMasterBus`).

## 1. نظرة عامة
- **التغيير المطلوب**: إرجاع صوت الجرس التحذيري (Buzzer) الخاص بالخطأ (❌) إلى نغمته التلفزيونية الأصلية القوية والواضحة.
- **نطاق التعديل**: يقتصر التعديل حصرياً على توليد صوت الخطأ داخل محرك الصوت Web Audio API دون تغيير أي عنصر بصري أو برمجي آخر.

## 2. تفاصيل التنفيذ الصوتي
```
┌──────────────────────────────────────────────────────────┐
│                     playStrike()                         │
│                                                          │
│  Tones: [98, 110, 116.54, 155.56, 233.08] Hz (Sawtooth)  │
│  LFO Vibrato: 40 Hz (Gain: 14) -> Oscillator Frequency   │
│  Envelope: Attack 0.015s -> Sustain 0.65s -> Release 0.85s│
└───────────────────────────┬──────────────────────────────┘
                            ▼
┌──────────────────────────────────────────────────────────┐
│            Master Audio Bus / Destination                │
└──────────────────────────────────────────────────────────┘
```

- **الترددات الصوتية**: `[98, 110, 116.54, 155.56, 233.08]` هرتز بموجة `sawtooth`.
- **تأثير الاهتزاز (LFO)**: مذبذب بتردد `40Hz` متصل بترددات الصوت لإعطاء نبرة جرس برنامج المسابقات الشهير.
- **المدة الزمنية**: `0.85` ثانية بظهور فوري وقوي (`gain: 0.45`).
