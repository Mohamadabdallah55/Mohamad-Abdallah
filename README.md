# Family Feud · تحدّي العائلة

يتطلب Node.js 24 و npm. شغّل:

```sh
npm ci --legacy-peer-deps
npm run dev
```

1. افتح `http://localhost:3000` وأنشئ مباراة. اضبط أسماء الفرق ومضاعفات الجولات قبل البداية.
2. من «ربط الشاشة / الهاتف» افتح رابط العرض على البروجكتر. امسح رمز المقدم **على هاتفه فقط**. على الشبكة المحلية، وصّل الجهازين بالشبكة نفسها واستعمل عنوان الشبكة الظاهر في نافذة الربط.
3. اضغط «فعّل الصوت» على شاشة الجمهور مرة واحدة. اختر سؤال الجولة وابدأ مع الفريق المسيطر. الخطأ الثالث ينقل اللعب إلى محاولة السرقة. كشف المتبقي بعد الاعتماد لا يغيّر الرصيد.
4. بعد الجولة الرابعة يظهر الفائز أو يُعلن التعادل. «مباراة جديدة» من واجهة المقدم.

للتشغيل بعد البناء: `npm start`. تحتاج اللعبة إلى خادم Node قيد التشغيل؛ الاستضافة الثابتة و`vite preview` لا يشغلان المزامنة. تُحفظ الغرف الجديدة في `.room-state`؛ على خادم مستقل استخدم مجلدًا دائمًا عبر `FAMILY_CHALLENGE_ROOM_DIR` وشغّل نسخة واحدة منه. استخدم شبكة محلية موثوقة أو HTTPS؛ رابط المقدم يمنح صلاحية كاملة للغرفة. ملفات الغرف القديمة تبقى في مكانها ولا تُفتح عبر نظام الربط الجديد.

بنك الأسئلة الموجود محفوظ. يمكن للمقدم إدخال أسئلته مباشرة من «بنك الأسئلة ← إضافة سؤال». الاختبارات: `npm test` و`npm run lint`.
